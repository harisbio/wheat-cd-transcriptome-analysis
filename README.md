# Analysis of public cadmium-stress RNA-seq data in wheat (*Triticum aestivum*)

Data and code accompanying:

> Haris, M., Batool, F., Hussain, S., Fatima, I., Nawaz, M. A., Mazhar, A., Azeem, F.
> *Biogenic iron oxide nanoparticles remediate textile wastewater and alleviate its phytotoxicity in
> wheat, with insights from public cadmium-stress transcriptome data.* (under review)

This repository reproduces the transcriptome results of the paper, main Figs. 4–9, Supplementary
Figs. S7–S11 and Supplementary Tables S3–S11, starting from the gene-level count matrix.

**The transcriptome data are not ours.** They are a reanalysis of a publicly archived dataset
(NCBI BioProject [PRJNA1124581](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1124581)) generated by
Cheng et al. (2025), *Plant Physiology and Biochemistry* 223, 109879,
doi:[10.1016/j.plaphy.2025.109879](https://doi.org/10.1016/j.plaphy.2025.109879). Please cite that
paper for the data themselves. The physiological and biochemical experiments reported in the
manuscript are separate work and are not part of this repository.

## What was analysed

Of the 24 libraries in the BioProject, only the **12 wild-type** libraries were used
(`input/sample_metadata.csv`, `qc/library_qc.csv`):

| Tissue | Condition | SRA runs |
|---|---|---|
| Root | Control | SRR29482939, SRR29482940, SRR29482941 |
| Root | Cd | SRR29482948, SRR29482950, SRR29482951 |
| Shoot | Control | SRR29482938, SRR29482958, SRR29482959 |
| Shoot | Cd | SRR29482945, SRR29482946, SRR29482947 |

The *TaNRAMP5*-knockout libraries were excluded. **Roots and shoots were analysed separately**
(design `~ condition`); mixing tissues in one model would confound tissue with treatment.

## Headline results

| | Roots | Shoots |
|---|---|---|
| Genes tested | 54,678 | 51,746 |
| DEGs (padj < 0.05, \|log2FC\| ≥ 1.5) | 9,219 (6,064 up / 3,155 down) | 6,989 (4,813 up / 2,176 down) |
| PC1 / PC2 | 95% / 3% | 79% / 13% |
| Top KEGG pathway | Glutathione metabolism (138 DEGs) | Phenylpropanoid biosynthesis (127 DEGs) |
| Stress-response PPI network | 576 proteins, 1,939 interactions | 388 proteins |

Root hub module (MCC, stress-response network): 1-Cys peroxiredoxin, glutathione peroxidases,
glutathione reductase, glutathione S-transferases, and ZIP / COPT / P-type Cu(+) metal transporters (all upregulated).

## Repository layout

| Folder | Contents |
|---|---|
| `input/` | `gene_counts_integer.csv` (tximport gene-level counts, 12 libraries); `sample_metadata.csv` |
| `annotation/` | gene → GO (`wheat_gene2go.tsv`), gene → UniProt (`wheat_gene2uniprot.tsv`), gene → protein name (`wheat_gene_annotation.tsv`), the raw UniProtKB export (`uniprot_taxon4565_export.tsv.gz`, accessed 13 Oct 2026) and KEGG REST files (`kegg_ref/`, organism `taes`, accessed 13 Oct 2026) |
| `results/` | DESeq2 results for all genes and for DEGs (root, shoot), gene lists, GO/KEGG enrichment tables, functional-group DEG lists, PPI node and hub tables, Fig. 9 family values, STRING networks (`string_networks/`, accessed 14 Oct 2026) |
| `qc/` | fastp JSON reports, Salmon mapping summary, combined library QC table |
| `scripts/` | all analysis and figure scripts (see below) |

All tabular files are plain text. `annotation/` and `string_networks/` files are **tab-separated**
(`.tsv`); everything else is comma-separated (`.csv`). The scripts read them with `read.delim` and
`read.csv` accordingly, so do not re-save them in the other format.

## Upstream processing (not re-run here)

1. Download FASTQ files from SRA (runs listed in `qc/library_qc.csv`).
2. QC: FastQC v0.12.1.
3. Trimming: `fastp v0.23.4 -i R1.fastq -I R2.fastq -o trimmed_R1.fastq -O trimmed_R2.fastq -w 8`
   (default filtering settings).
4. Quantification: Salmon v1.10.2 `quant` (selective alignment, `-l A`, 8 threads) against an index
   of the *T. aestivum* IWGSC RefSeq v1.1 cDNA transcriptome (Ensembl Plants release 61).
5. Gene-level summarisation with tximport (`countsFromAbundance = "no"`, counts rounded) using the
   transcript → gene map from the FASTA headers, giving `input/gene_counts_integer.csv`.

Read-level QC and mapping rates for each library are in `qc/library_qc.csv`: 98.9% of root reads were
retained after trimming (93.3–94.4% of bases at Q30) with a mean Salmon mapping rate of 74.3%; shoots
were 93.7–94.3% Q30 with a mean mapping rate of 79.8%.

## Scripts and run order

The scripts expect the flat working-folder layout used during the analysis: all scripts, the
annotation files and the result folders in one directory, called `<work>` below. `<counts>` is the
folder containing `gene_counts_integer.csv`. To reproduce that layout from this repository:

```bash
mkdir work && cd work
cp ../scripts/* ../annotation/*.tsv .
cp -r ../annotation/kegg_ref .
cp -r ../results/* .
```

| Step | Script | Produces |
|---|---|---|
| 1 | `python build_gene2go.py <uniprot export .tsv> <work>` | gene → GO / UniProt / protein-name tables |
| 2 | `Rscript fig4_qc_de_figures.R <counts> <work>` | DESeq2 + apeglm results, DEG lists, Fig. 4 / Fig. S7 |
| 3 | `Rscript fig5_go_enrichment.R <work>` | GO enrichment tables, Fig. S8 (dot plots) |
| 4 | `Rscript fig5_go_circle.R <work> Root Fig5_GO_Root_main` | Fig. 5 (GO circle plots) |
| 5 | `Rscript fig6_kegg.R <work>` | KEGG enrichment, Fig. 6 / Fig. S9 (needs `kegg_ref/`) |
| 6 | `Rscript fig7_gene_groups.R <counts> <work>` | functional gene groups, Fig. 7 / Fig. S10 |
| 7 | `python ppi_fetch_string.py <work> Root Fig7_GeneGroups_Root_main 400` (and `Shoot FigS_GeneGroups_Shoot_supplementary`) | STRING ID mapping and networks (`ppi/`) |
| 8 | `Rscript fig8_ppi.R <counts> <work> Root Fig8_PPI_Root_main Fig7_GeneGroups_Root_main` (and the Shoot equivalent) | PPI figures, MCC hub rankings, Fig. 8 / Fig. S11 |
| 9 | `python fig9_model.py <work>` | Fig. 9 and family values (Table S11) |
| 10 | `python build_supplementary.py ...` | supplementary tables, figures and the submission package |

`figure_theme.R` (shared colours) and `fig_helpers.R` (circular heatmaps, label shortening) are
sourced by the figure scripts and are not run directly.

Step 7 queries the STRING API over the network. The responses we used are archived in
`results/string_networks/`, so steps 8–9 can be run offline without repeating the query.

## Key parameters

* Low-count filter: ≥ 10 counts in ≥ 3 samples, applied per tissue.
* DEGs: Benjamini–Hochberg adjusted *p* < 0.05 and |apeglm-shrunken log2FC| ≥ 1.5.
* PCA and heatmaps: variance-stabilising transformation (`vst`, `blind = TRUE`); PCA on the 500 most
  variable genes, Fig. 4F heatmap on the 1,000 most variable genes.
* GO: UniProtKB annotations propagated to all ancestor terms with GO.db; one-sided hypergeometric
  test against the tested genes carrying ≥ 1 annotation; terms with 10–500 genes; FDR < 0.05;
  redundancy filter at Jaccard ≥ 0.7 against a more significant term.
* KEGG: UniProt → KEGG gene mapping; pathways with ≥ 5 genes; FDR < 0.05. Tested for all DEGs and,
  separately, for up- and downregulated DEGs. Global and overview maps (`map011xx`, `map012xx`) are
  tested but not plotted — 41 of the 45 significant root pathways are non-overview.
* Functional groups (GO term plus all descendants): oxidative stress GO:0016209, GO:0006979,
  GO:0004364; transcription factors GO:0003700; transporters GO:0005215.
* PPI: STRING v12.5, taxon 4565, combined score ≥ 0.4. Hub ranking by Maximal Clique Centrality as
  in cytoHubba — the sum over all maximal cliques containing the node of (|C| − 1)! — computed on the
  union of the three functional groups. The all-DEG ranking (Table S10) uses score ≥ 0.7, because
  clique enumeration is intractable at 0.4 for 8,902 proteins.

### Reproducing the stress-response network

`results/string_networks/` contains one edge list per functional group plus `network_all_DEGs.tsv`,
but not the stress-response network itself. `fig8_ppi.R` derives it by filtering
`network_all_DEGs.tsv` to edges where **both** partners belong to the union of the three functional
groups, which keeps the cross-group interactions that the per-group files omit. That yields the
576 proteins and 1,939 interactions reported in the paper; the per-group edge lists alone give only
522 and 1,503.

## Notes and caveats

* UniProt, KEGG and STRING change between releases. The exact files we queried are included so the
  results can be reproduced as published rather than as the databases stand today.
* Most IWGSC v1.1 genes have no reviewed UniProt entry, so protein names are frequently
  "Uncharacterized protein". Gene-family assignments in Fig. 9 / Table S11 are regular-expression
  matches on UniProt protein names and are therefore approximate; counts can differ from the
  GO-based groups in Fig. 7, which are restricted to GO term membership.
* The two superoxide dismutase DEGs in roots are **downregulated**, so the increased SOD activity
  measured in the pot experiment cannot be attributed to transcriptional induction in this dataset.
* Ranking hubs across all DEGs returns mostly ribosomal proteins (Table S10). The paper uses the
  stress-response network instead, which is a deliberate choice and is stated in the Methods.
